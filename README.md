# Rnx DjVu Raw → OCR

Приложение **C# / WinUI 3** для Windows: открывает DJVU со сканами, распознаёт все страницы локально и сохраняет отдельный DJVU с поисковым текстовым слоем и координатами слов.

## Готовое приложение

После публикации запустите `artifacts\app\RnxDjvuRaw2Ocr.App.exe`. Переносить нужно **всю папку** `artifacts\app`, включая подпапку `tools`. Установка .NET и Windows App Runtime на целевом компьютере не требуется: они включены в сборку. Целевая система — Windows 10 2004 (19041) и новее, x64.

1. Выберите или перетащите файл `.djvu` / `.djv`.
2. Укажите выходной файл. По умолчанию предлагается `имя.ocr.djvu`.
3. Выберите языки: `rus+eng`, `rus`, `eng` или другие установленные модели.
4. Нажмите **«Распознать документ»**.
5. Откройте результат в просмотрщике с поддержкой текстового слоя DJVU, например DjView. Поиск и копирование текста выполняются в просмотрщике.

Исходный файл не перезаписывается. Для замены другого существующего выходного файла требуется подтверждение. Пока обработка не завершилась и текст не прочитан обратно для проверки, результат не публикуется. Отмена завершает дочерние процессы и удаляет временные данные. Пустые страницы допустимы и учитываются в отчёте.

## Подготовка из исходников

Требуются .NET SDK 10 и Windows SDK 10.0.26100 (например, из Visual Studio с инструментами разработки для Windows). Пакеты NuGet восстанавливаются при сборке.

Из корня репозитория в PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Setup-Tools.ps1
dotnet build .\RnxDjvuRaw2Ocr.sln -p:Platform=x64
dotnet run --project .\src\RnxDjvuRaw2Ocr.App -p:Platform=x64
```

`Setup-Tools.ps1` скачивает фиксированные версии DjVuLibre 3.5.29, Tesseract 5.5.3 и русскую/английскую модели `tessdata_fast` 4.1.0. Проверяет SHA-256, распаковывает в `tools` и не запускает установщики OCR. Для DjVuLibre рядом размещаются необходимые x86-библиотеки Visual C++ из официального пакета Microsoft VCLibs 14.0.33321.0. Если 7-Zip отсутствует, скрипт использует локальное административное извлечение его MSI. Интернет нужен для первоначальной подготовки и восстановления NuGet; само распознавание работает без сети.

Пути к инструментам определяются по папке `tools` рядом с приложением или выше по дереву, стандартным каталогам установки и `PATH`. Их можно изменить в разделе **«Инструменты OCR»**. Настройки хранятся в `%LOCALAPPDATA%\RnxDjvuRaw2Ocr\settings.json`.

Дополнительные языки: поместите LSTM-совместимые `.traineddata` из [tessdata_fast](https://github.com/tesseract-ocr/tessdata_fast) или [tessdata_best](https://github.com/tesseract-ocr/tessdata_best) в выбранную папку `tessdata`, нажмите «Проверить инструменты» и введите коды через `+`. Порядок языков влияет на распознавание; для преимущественно английского документа можно использовать `eng+rus`.

## Публикация

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Publish.ps1
```

Создаёт автономную папку `artifacts\app` с WinUI, .NET и OCR-инструментами. Это переносимая сборка, а не MSIX. При распространении учитывайте лицензии нативных зависимостей из `THIRD-PARTY-NOTICES.md` и сохраняйте файлы лицензий вместе с ними.

## Как устроена обработка

- `djvused save-bundled` создаёт рабочую копию. Поддерживаются одиночные, bundled и indirect DJVU; компоненты indirect-документа должны быть доступны рядом с его индексом.
- `ddjvu -format=tiff -1` извлекает по одной странице в исходном разрешении.
- Tesseract LSTM (`--oem 1`) возвращает TSV с блоками, абзацами, строками и прямоугольниками слов.
- Координаты переводятся из начала в левом верхнем углу изображения в левый нижний угол DJVU. Учитывается поворот из INFO, хранятся UTF-8-строки с переносимыми octal-escape последовательностями.
- `djvused set-txt` добавляет слой `TXTz`. Сжатые изображения, порядок страниц, закладки и заголовки страниц сохраняются без повторного кодирования.
- Текст каждой страницы читается обратно и сверяется с OCR. Готовый файл копируется во временный файл в папке назначения и публикуется переименованием; при разрешённой замене используется `File.Replace`.

Обрабатываются все страницы последовательно: одновременно на диске находится только один извлечённый растр. Требуется свободное место для рабочей копии книги, одного TIFF и итогового файла. Временные данные создаются в `%TEMP%\RnxDjvuOcr`.

Качество OCR зависит от сканов и языковой модели. Автоматический режим подходит для обычных книжных страниц; для единого текстового блока и разрозненных фрагментов доступны отдельные режимы. Приложение учитывает сохранённую ориентацию DJVU, но не исправляет наклон, не определяет автоматически перевёрнутый скан и не восстанавливает формулы или структуру таблиц. Если текстовый слой уже есть, он заменяется новым.

## Проверки

```powershell
# Быстрые тесты без нативных OCR-инструментов
dotnet test .\tests\RnxDjvuRaw2Ocr.Tests --filter 'Category!=Integration'

# Все тесты, после Setup-Tools.ps1
dotnet test .\tests\RnxDjvuRaw2Ocr.Tests
```

Сквозной тест генерирует пятистраничную книгу с русским и английским текстом, четырьмя ориентациями и пустой страницей. Проверяет текст, пути с кириллицей и пробелами, indirect DJVU, сохранение закладок и заголовков, неизменность исходника, побайтовое совпадение сжатых графических chunks и совпадение отрендеренных изображений. Образцы находятся в `artifacts\integration`.

## Структура

- `src/RnxDjvuRaw2Ocr.App` — интерфейс WinUI и настройки.
- `src/RnxDjvuRaw2Ocr.Core` — OCR-конвейер, запуск процессов, TSV и текстовые зоны DJVU.
- `tests/RnxDjvuRaw2Ocr.Tests` — модульные и сквозные проверки.
- `scripts` — подготовка инструментов и публикация.
